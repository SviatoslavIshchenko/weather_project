# ☀️ Weather App — вебзастосунок прогнозу погоди

Навчальний **Step Project**, створений на **Django**. Застосунок дозволяє зареєстрованим користувачам переглядати поточну погоду в обраному місті, зберігати власну історію пошуків, аналізувати її та експортувати дані.

## Можливості

- **Облікові записи:** реєстрація з email і паролем, вхід та вихід із системи.
- **Погода:** пошук за назвою міста через OpenWeatherMap API; температура, відчутна температура, вологість, швидкість вітру, атмосферний тиск та опис погодних умов.
- **Історія:** збереження пошуків у SQLite окремо для кожного користувача; перегляд та видалення записів, очищення історії.
- **Фільтрація:** пошук за містом і діапазоном дат.
- **Сортування:** за датою, температурою або назвою міста.
- **Пагінація:** 5, 10, 20 або 50 записів на сторінці.
- **Аналітика:** кількість пошуків за містами, середня, мінімальна та максимальна температура; таблиця та графіки на Chart.js.
- **Експорт:** CSV з історією пошуків та Excel (`.xlsx`) з історією й окремим аркушем статистики міст.

> Статистика розраховується за **збереженими результатами пошуків**, а не за незалежними щоденними метеорологічними спостереженнями. Повторні пошуки враховуються як окремі записи.

## Встановлення та запуск (Windows / PowerShell)

### 1. Клонувати репозиторій

```powershell
git clone https://github.com/SviatoslavIshchenko/weather_project.git
cd weather_project
```

### 2. Створити та активувати віртуальне середовище

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Якщо PowerShell забороняє запуск сценаріїв, можна активувати середовище через командний рядок (`.venv\Scripts\activate.bat`) або налаштувати інтерпретатор `.venv` у PyCharm.

### 3. Встановити залежності

```powershell
python -m pip install -r requirements.txt
```

### 4. Налаштувати змінні середовища

Отримайте API-ключ на [OpenWeatherMap](https://openweathermap.org/api). Створіть файл `.env` у корені проєкту. **Назви змінних мають відповідати тим, які зчитує `weather_project/settings.py`.** Наприклад, якщо налаштування використовують наведені нижче назви:

```dotenv
OPENWEATHER_API_KEY=your_openweathermap_api_key
SECRET_KEY=your_unique_django_secret_key
DEBUG=True
```

Не публікуйте `.env`, API-ключ або Django `SECRET_KEY` у GitHub. Файл `.env` виключено правилами `.gitignore`.

### 5. Застосувати міграції

```powershell
python manage.py migrate
```

SQLite створить локальну базу `db.sqlite3` за потреби. Файл бази даних не додається до репозиторію.

### 6. Запустити сервер

```powershell
python manage.py runserver
```

Відкрийте в браузері: **http://127.0.0.1:8000/**.

Зареєструйте користувача, увійдіть у систему, введіть назву міста та виконайте пошук погоди. Результати можна переглянути на сторінці історії.

## Перевірка проєкту

```powershell
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py migrate --check
```

Рекомендовано вручну перевірити реєстрацію, вхід/вихід, пошук коректного й неіснуючого міста, збереження історії, фільтрацію, сортування, пагінацію, видалення та завантаження CSV/Excel.

## Примітки

- Для роботи з погодою потрібні доступ до інтернету та чинний API-ключ OpenWeatherMap.
- Дані про погоду надходять із зовнішнього сервісу й можуть змінюватися між запитами.
- Проєкт призначений для навчання та локального запуску. Для публічного розгортання необхідно окремо налаштувати безпеку, `DEBUG=False`, `ALLOWED_HOSTS`, обслуговування статичних файлів та інші production-параметри Django.
